TEMU助手隐私权政策

生效日期：2026年10月27日

TEMU助手是一款面向跨境电商卖家的 Chrome 扩展。扩展的单一用途是帮助用户在已登录的店铺和业务系统中查看、整理、分析及导出与店铺运营直接相关的数据，并提供库存、销量和商品风险提醒。

1. 适用范围

本隐私权政策适用于 Chrome 扩展“TEMU助手”（以下简称“本扩展”）。本扩展是独立开发的第三方效率工具，并非 TEMU 官方产品，也不代表已获得 TEMU 的授权、认可或背书。TEMU 及相关名称、标识和商标归其权利人所有。

2. 我们处理的数据

为实现用户主动使用的功能，本扩展可能处理以下数据：

  • 账号与会话信息：当前 TEMU Seller Central、CFTEG 及受支持业务系统的登录状态、会话 Cookie 或令牌，以及 CFTEG 返回的用户名、用户 ID、岗位和账号状态。此类信息仅用于确认登录状态并代表用户向已登录系统发起必要请求。
  • 店铺与商品数据：店铺名称和标识、站点或区域、商品名称与图片、SPU、SKU、SKC、商品货号、规格、价格、成本、库存、销量、活动状态、限流站点及其他商品运营信息。
  • 订单与经营数据：订单号、订单状态、创建时间、发货信息、费用、结算数据、销售额、申报价、仓库及物流状态等用户自有店铺的业务数据。
  • 风险与分析数据：为生成下架站点、高价限流、活动亏损、滞销缺货等提醒而形成的业务快照、计算结果、已读状态和更新时间。
  • 用户设置和操作数据：用户选择的店铺、管理模式、站点、主题、筛选条件、悬浮按钮位置、任务运行状态以及导出记录。
  • 网页内容和网站活动：仅限本扩展明确支持的网站中，为完成用户请求所必需的页面地址、页面内容及网络请求结果。

本扩展不会要求用户向扩展输入 TEMU、CFTEG 或其他业务系统的账号密码，也不会保存用户密码。

3. 数据使用目的

上述数据仅用于以下目的：

  • 展示店铺工作台、商品、订单、库存、销量、结算和物流数据。
  • 执行用户主动触发的查询、筛选、复制、导出、跳转及页面辅助操作。
  • 保存必要的本地业务快照，并生成库存、价格、活动和商品风险提醒。
  • 验证用户是否已登录受支持的系统，并保持扩展功能正常运行。
  • 保存本地设置、任务状态、历史记录和已读状态。
  • 在用户主动点击“搜索同款”时，使用商品主图查找相似商品。

本扩展不会将数据用于个性化广告、重新定向广告、信用评估、保险或贷款资格判断，也不会出售用户数据或将数据用于与本扩展单一用途无关的目的。

4. 数据传输与第三方服务

本扩展会在用户已登录并主动使用相关功能时，与提供相应业务功能的服务进行必要通信：

  • TEMU Seller Central：从 agentseller.temu.com、agentseller-us.temu.com 和 agentseller-eu.temu.com 读取用户自有店铺的商品、订单、库存、销量、价格、活动和结算等业务数据。
  • CFTEG：从 cfteg.com 和 www.cfteg.com 验证当前登录状态，并读取用户有权访问的商品及成本数据。
  • 同款搜索服务：仅在用户主动点击同款搜索功能时，将所选商品主图发送至 api.temaishuju.com 进行图片搜索；该请求不携带 TEMU 或 CFTEG 登录凭据。
  • 受支持的店铺运营、仓储或物流服务：仅在用户主动使用相应功能时，与扩展清单中声明的网站通信，以查询或处理必要的订单、仓储或物流信息。

除完成上述用户请求所必需的通信外，开发者不会向广告平台、数据经纪商或其他无关第三方出售、出租或共享用户数据。

5. 本地存储与保留

本扩展使用 Chrome 本地存储、网页本地存储和 IndexedDB 保存用户设置、店铺列表、业务快照、任务状态、风险记录及缓存数据。这些数据保存在用户当前浏览器环境中。

本扩展只在实现相应功能所需的期限内保留本地数据。用户可以通过扩展提供的清理或重置功能、Chrome 的扩展数据清理功能，或者卸载本扩展来删除本地保存的数据。

6. 浏览器权限使用说明

本扩展使用以下 Chrome 权限来实现核心功能：

  • storage：保存用户设置、任务状态、业务快照、缓存和风险提醒记录。
  • alarms：按计划执行用户店铺的本地库存快照和风险复核任务。
  • cookies：读取受支持网站中浏览器已存在的登录会话，以完成用户请求；不用于获取或保存密码。
  • notifications：在用户启用或触发相关任务时显示与店铺运营有关的结果提醒。
  • tabs：查找、打开或聚焦受支持的网站标签页，并判断对应系统是否处于登录状态。
  • scripting：在受支持的网站页面中执行必要的页面辅助逻辑和只读数据请求。
  • webRequest 和 declarativeNetRequest：仅为扩展自身发出的受支持业务请求处理必要的请求头和兼容性规则。
  • host_permissions：仅访问扩展清单中声明、且与店铺运营、仓储或物流功能直接相关的网站。

7. 数据安全

本扩展采用合理的技术措施限制数据访问范围，外部接口优先使用 HTTPS，并将网络规则限定于扩展自身的请求。本扩展不从远程服务器下载并执行 JavaScript 或 WebAssembly 代码。

用户应妥善保护自己的浏览器和各业务系统登录状态，不应将已登录设备交由未经授权的人员使用。

8. 用户选择和权利

用户可以：

  • 退出相应网站，使本扩展无法继续使用该网站的登录会话。
  • 停止使用特定功能，以避免该功能所需的数据处理或传输。
  • 清除扩展本地数据、网站数据和缓存记录。
  • 卸载本扩展，以删除扩展保存在当前浏览器中的本地数据。
  • 通过 Chrome Web Store 商店详情页公布的开发者联系方式提出隐私相关问题或请求。

9. Limited Use 声明

本扩展对用户数据的处理遵守 Chrome Web Store 用户数据政策及 Limited Use 要求。用户数据只会用于实现本政策所述的单一用途，不会被转移用于个性化广告、营销分析、信用评估或其他与扩展功能无关的目的。

10. 儿童隐私

本扩展面向店铺经营和企业运营人员，不以儿童为目标用户，也不会有意收集儿童个人信息。

11. 政策更新

如果本扩展的功能、权限或数据处理方式发生变化，本政策将相应更新。更新后的政策会标明新的生效日期；发生重大变化时，开发者会在适用情况下通过 Chrome Web Store 商店页面或扩展界面进行说明。

12. 联系方式

如对本隐私权政策或数据处理方式有任何问题，请通过 TEMU助手的 Chrome Web Store 商店详情页中公布的开发者联系方式与开发者联系。
